# eng::fs — Caminhos e I/O de Arquivos (FASE 3)

> Dono único da abstração de path e I/O. Decisões completas:
> [ADR-027](../adr/ADR-027-filesystem-abstraction.md) (fronteira com
> platform: [ADR-026](../adr/ADR-026-platform-fs-boundary.md)).

## Posição no grafo

```
eng::core ──▶ eng::fs ◀── eng::log (declarada)
```

`fs` NÃO depende de platform (a fronteira é a razão do ADR-026). Native e
Memory são paritários em contrato — testes de assets/serial/project rodam
contra as duas sem mudança de comportamento.

## API essencial

```cpp
eng::fs::Path p{"/proj/assets"} / eng::fs::Path{"scenes/a.json"};
p.normalized().isWithin(eng::fs::Path{"/proj/assets"});  // anti-traversal
p.str();      // forma genérica (o que se persiste)
p.parent() / p.filename() / p.stem() / p.extension();

eng::fs::NativeFileSystem native;   // std::filesystem (error_code) + FILE*
eng::fs::MemoryFileSystem memory;   // árvore ordenada em RAM (testes)
native.readAllText(path);           // Result<std::string> — nunca lança
native.writeAllBytes(path, bytes);  // NÃO cria pais (mkdirs antes)
native.remove(path);                // arquivo OU diretório vazio → bool
native.list(dir, /*recursive=*/true); // ordem determinística
```

`Path` ENVOLVE `std::filesystem::path` (ctor com tag `FromNative` para
desambiguar conversões). `valid()` = não-vazio e sem NUL — rejeitado com
`InvalidArgument` em toda operação de I/O.

## Invariantes testadas

- writeAll não cria pais; remove só apaga vazio; list determinístico;
- round-trip Memory e Native (tmpdir real) com bytes binários/NUL;
- `isWithin` por COMPONENTE ("/data-base" não está dentro de "/data");
- erros NotFound/InvalidArgument com mensagens claras.

## Concorrência

Thread-compatible (instâncias independentes em threads distintas);
instância única NÃO é segura para mutação concorrente (ADR-034).
